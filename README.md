# Premature Mortality in Jamaica

This repository contains analysis plans and statistical code developed for a PhD thesis in Epidemiology examining premature mortality in Jamaica.

## Project Objectives

### Objective 1: Temporal Trends and Patterns

To describe trends and patterns in overall and cause-specific premature mortality in Jamaica between 2010 and 2019.

Materials are available in the [`objective-1-trends`](objective-1-trends/) folder.

### Objective 2: Socioeconomic Inequalities

To examine geographic and socioeconomic variation in premature mortality in Jamaica. Materials will be added following completion of the analyses.

### Objective 3: Economic Burden

To estimate the economic burden associated with premature mortality in Jamaica. Materials will be added following completion of the analyses.

## Data Availability

The individual-level mortality data were obtained from Jamaica’s Registrar General’s Department and are subject to confidentiality restrictions. Individual-level data and derived record-level datasets are not included in this repository.

Population and supplementary data were obtained from the relevant Jamaican government agencies, as described in the analysis plans.
